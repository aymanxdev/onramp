# Security

Please do not open public issues for vulnerabilities.

Report privately via GitHub: Security > Report a vulnerability. You will get a reply within 72 hours.

In scope: the edge function at /api/route, abuse-control bypasses, secret leakage, XSS in prompt rendering, supply-chain issues in dependencies.

Out of scope: rate-limit thresholds being "too low", anything on Anthropic's own services (report those to Anthropic).

Onramp keeps aggregate daily counters only (see DATA.md). Daily hashed IP counters expire within 24 hours.
